# Awdsain — Minimalist & Significant Brand Showcase

Welcome to the official web showcase repository for **Awdsain** (*aw-dee-sign*), a Malaysia-based graphic design and brand identity studio founded by Angel Won.

This project is a static responsive website designed to highlight Awdsain's portfolio, design philosophy, and agency services in a sleek, minimalist digital space.

## 🌟 About Awdsain

Awdsain focuses on creating impactful visual identity systems guided by the principle: **"Minimalist but significant."** 

### Specializations & Services
- **Brand Identity & Strategy:** Crafting cohesive brand messaging and visual aesthetics.
- **Logo Design & Typography:** Custom monograms, hand-lettered logotypes, and minimalist icon design.
- **UI/UX Design:** User-centric mobile and web interface layouts.
- **Creative Services:** Curated visual direction for emerging and established brands.

---

## 🛠️ Tech Stack & Features

- **Frontend:** HTML5, CSS3, JavaScript
- **Typography:** Custom web fonts (Cremona, NewYork, Sofia Pro)
- **Deployment:** GitHub Pages
- **Design Principles:** Fully responsive layout, clean aesthetic, optimized media delivery
